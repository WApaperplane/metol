### 1.1 平台

```
SoC：DRIMe5（双核）
├─ Linux 侧（ARM / Tizen，rootfs 只读 96% 满）—— di-camera-app 等全部用户态
└─ p7 侧（Cortex-A9 RTOS 固件，12,075,648 B，占 DRAM 高段 0x81xxxxxx）
```

| L3 mod_gui | 菜单覆盖层（4 控件 / 2 列 / 点击即退） | ✅ 随 release 交付 |
| **L4 p7 固件** | 改 ISP 固件 | ✅ **2026-10-11 夜 G4 全绿（U4+U5）后放行** —— ★ 唯一不可逆层，动手前先读 §5 死路清单 |

### 3.2 关键地址 / 接口表

| 对象 | 值 | 说明 |
|---|---|---|
| EP 3DLUT 寄存器 | `0x2082B000` | dev-ep.c 权威定义 |
| LUT 表格式 | `4913 × 4B {R,G,B,pad}`，索引 `((B*17+G)*17+R)*4` | 17 级非均匀格点 `{0,16,…,240,255}` |
| 4 组内置 LUT 缓冲 | `0x810FD100` / `0x81106B00` / `0x81115200` / `0x81101E00`（p7 空间） | Linux 读不到，只能经驱动 |
| CMA 共享区 | `0x94000000`，144 MB | `/dev/d5_sma` 可读写 |
| ISP 参数块 | 块 A `0x20821300` / 块 B `0x20821700` | 21 槽 × 2 通道 |
| PW 参数模型 | `PW_BASE=0xa3ec`、步长 52/4；14 槽 × 7 维 | 外部直推 id = `0x110/0x111/0x112`（SAT/SHARP/CON） |
| MCB | 68 条命令 / 8 域 | `capture_command_string` 全表 |
| 生效判据工具 | `iqr`（184 个 ID） | **本项目唯一客观判据**：「改了生效没有」只信它 |

### 3.3 相机端接入

- telnet **23** / FTP **21**（root，空密码）；Web 遥控 80 / 缩略图与 push 走 **8080**。
- 相机工作目录 `/opt/usr/nx-ks/`（≡ diff p14，刷固件不覆盖，mod 唯一安全落点）。
- SD 卡触发链：`info.tg` → `nx_cs.adj` → `dfmsd` 自动执行 `/mnt/mmc/install.sh`（无需按键）。

## 5. ★ 死路清单（全部烧过实机时间，勿再走）

| # | 死路 | 判据一句话 |
|---|---|---|
| 1 | 指望 mod_gui 迭代 | 4 控件/2 列/点击即退 —— 只能取代不能扩展 |
| 2 | 在 p7 里找菜单 | 搜 Font/DrawText/Dialog/Widget 全 0 ⇒ p7 无界面 |
| 3 | 长按 / 连击 / 组合键 | 内核先消费按键，架构级不可得 |
| 4 | 纯寄存器写进固件 | 必须走 DMA / 共享内存 |
| 5 | PC 直连刷机 | iLauncher 只是"拷文件到 SD，由相机自己发起" |
| 6 | `/dev/mem` 读 p7 / MMIO | 实测全 Bad address ⇒ 一律走驱动 |
| 7 | 用户态读 p7 LUT 缓冲 | 缓冲在 p7 地址空间，Linux 永远读不到 |
| 8 | 猜 3D LUT 表格式 | 已解出（§3.2），别再猜 |
| 9 | 用 `st firmware up` 宽松入口"证明"官方 UI 会过 | 两个入口校验强度不同 |
| 10 | `epmc` 按"个数"直觉调用 | `nreg` 是**结束下标**不是个数（写错得假结论） |
| 11 | 外部直推 R/G/B/HUE | 10-10 上机负结论 + 静态铁证：归一化器只认 `0x100–0x12e` |
| 12 | 成片直灌 LUT | E4 实测死路（拍片流程主动重配置 LUT 档位池） |
| 13 | 自绘全屏 UI | 窗口不显示 + 单核拖死风险；已改走 mod_gui |

**硬性操作约束**（会流血的那种）：

1. `epmc` 单次读 **≤256 regs**（读 1024 会压死相机，实测 3 次）。
2. LUT 灌入用 `sel=0`（厂商通道）；`sel=2` 会花屏。
3. LUT 物理地址 **256 B 对齐**；每次灌表前必跑 `cmapick2` 选安全落点。
4. **不要半按快门**（会触发 p7 抢回 LUT 指针——正常行为，lutsentinel 会恢复）。
5. 一份 telnet 会话只跑一条命令（结果经 FTP 取回）。
6. 上机批次留散热间隔（连续 ~40 分钟只读后相机过热自动重启，实测）。
7. 交叉编译一律 **-O0**（否则段错误）；相机脚本必须 **LF**（CRLF 不兼容）。
