⇒ ★★ **改配置 / 加参数 / 调布局全都无效 —— 那是重写，不是迭代。**
⇒ 正确动作是**取代**（原生 EFL 视图），mod_gui 降级为**兜底 + 高危入口**（Q2 已定）。

### 4.2 固件层 gamma / color：已判定不可解 ⛔

**判据链（Q3 实测，零刷写风险）**：

```
自证：epmc 8 4 → 3dlut OnOff=1 / Cfg=0x100 / LUT0=0x81115200
      ★ 与 10-06 实机记录逐项一致 ⇒ 读取通路有效（否则「全零」不可信）

mc 块（0x20824000 / 8KB，此前完全没碰过）逐段扫描：
  子模块0  +0x0fc = 0x13040614   ← 0x1304 系列
  子模块1~7       = 0x13030814   ← 0x1303 系列（全部相同）
  3dlut   +0x0fc = 0x13020614   ← 同族 ⇒ 三星自研 ISP 的 IP 版本寄存器布局
  唯一非 IP ID：+0x43c = 4       ← mc 块是活的，不是死区
⇒ ★★ EP 侧是【控制面 + 状态面】，不是【参数存储面】
⇒ ★★★ H1（gamma 走 EP 寄存器直写）被证伪，H2 成立
```

⇒ ★★★ **按铁律 86：gamma / color 的固件侧改动一律不得启动。**
⇒ ★★ 这不是保守 —— 那 184 个 IQ 参数只存在于 p7 侧数据结构，而那些位置 Linux 侧**全部不可读**。

### 4.3 Linux 读 p7 内存：所有通道已排除 ⛔

```
✘ /dev/mem            ★ 整体不可用（连已知可读的 0x2082b000 也 Bad address）
✘ /proc/iomem         ★ 是空的（不只段错误）
✘ /proc/maps          只有用户段
✘ EP GET_PHYS_REG_INFO 只给硬件寄存器
✘ SMA mmap            受 region 限制（SMA_ALLOC 12 组全 EFAULT）
✘ IPCC                ipcc_open 返回 -1；裸 ioctl(IPCC_INIT) → ★ p7 (A9) Oops
⇒ 方案 A（改 p7 的 DAT_003837f0 指向我的表）不可行
```

### 4.4 3D LUT 偏色：不是技巧问题，是工程量问题

```
根因：表数据格式由 p7 固件决定，寄存器里【没有格式字段】，硬件读不回来
⇒ 只能改 p7 固件 ⇒ 但 3.7 的通道不通 ⇒ 死锁

已否证的结论（★ 别再走回头路）：
✖ 表长 = 19652（等距推导）—— 错，0x4D00 是【槽位大小】
✖ 表长 = 29478（17³×3×u16）—— 错，依据是 save_lut 读回 = 自证循环
✖ save_lut 能读回硬件表 —— 否证，清零缓冲实测读回全零
✖ 「没等 DMA 中断导致半成品」—— 物理不成立，30KB DMA = 15µs，我等了 200ms
✖ 「某个通道是亮度」—— 未证实，三张单色表全偏色
```

### 6.0 ★★★★ 键名表与触发规则（静态提取，非猜测）

### 7.1 上机纪律（铁律 90，三版踩坑定型）

```
① 上传前先探 21 端口 ⇒ 不在线就退出，★ 绝不盲发

### 7.2 ★★★ 单核相机真实资源边界（铁律 88，我压死相机 5 次换来的）

```
★ 实测安全边界（9 次实测，可复用硬数据）：
   ✅  64 regs (256B)   ✅ 256 (1KB)   ✅ 512 (2KB)   ✅ 768 (3KB)
   ✘  1024 regs (4KB)   ✘ 2048 regs (8KB，即使已改「只输出非零」)
   ⇒ ★★★ 上限 = 768 regs（3KB）

★ 我犯的最贵的一个认知错误（第一次事故后的结论被自己的实验推翻）：
   ✘「危险的是输出量」—— 已改 nzonly（输出降 1/50）仍然挂
   ✔「危险的是单次循环长度」—— 768✅ / 1024❌ 边界清晰
⇒★★★★★ 定案：危险的是【单次运行的循环总量】，输出量是次要因素
⇒★★★ 这解释了 216MB CMA 探测为何安全：cmapick2 每 4MB 就 usleep
⇒ ⇒★ 「单核铁律」的真正内核 = 【不是总量要小，而是单次连续段要小】
```

★ **配套两条**：
- 铁律 89：**需要「等人操作」的探针在单核上结构性危险**（会让进程挂 20 秒不走）。
  正确形态 = 脚本读一次 → 退出 → 人操作 → 脚本再读一次 → 本地对比。
- 铁律 104：★ **后台常驻的东西更要小心** —— 单次段再小，累积起来也能压死相机。

### 7.3 脚本与传输（铁律 99~101）

```
