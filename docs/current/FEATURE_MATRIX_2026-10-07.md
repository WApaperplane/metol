### 4.2 ★★★ T2 判定结果（Q3 实机普查完成，12:35）

> 报告 `docs/current/Q3_EP_GAMMA_PROBE_2026-10-07.md`

**自证先行**（否则"全零"不可信）：

```
epmc 8 4 → 3dlut: OnOff=0x1 / Cfg=0x100 / Pulse=0x0 / LUT0=0x81115200
            ★ 与 10-06 实机记录逐项一致 ⇒ 读取通路有效
```

**主判据**：

```
epmc 2 64 → mc 块(0x20824000/8KB) 前 256B：全零
             唯一非零 = +0x0fc = 0x13040614
             ★ 该值与 3dlut 块 +0x0fc 同值 ⇒ 芯片 IP ID，不是参数
```

| 参数        | EP 侧可读寄存器         | T2             | 结论       |
| --------- | ----------------- | -------------- | -------- |
| **gamma** | mc 前 256B 无       | ★★ **不可解**     | ★ **冻结** |
| **color** | 同上                | ★★ **不可解**     | ★ **冻结** |
| **NOG**   | ★ **寄存器区只有 256B** | ★★★ **原理上不可解** | ★ **冻结** |

⇒ ★★★ **按铁律 86，这三项的固件侧改动一律不得启动。**

### 4.3 ★★★ Q3 开出的新突破口（比 gamma 本身更重要）

| 事实                                        | 推论                          |
| ----------------------------------------- | --------------------------- |
| ★ `iqr` 能看到 **184 个 `eIQ_ID_*`**          | ⇒ **它们必然存在某个可读结构里**         |
| ★ `mc` 块 = `0x20824000` / **8KB**，此前完全未碰过 | ⇒ ★ **头号候选**                |
| ★ gamma/color 不在 mc 前 256B                | ⇒ **要找的是"统一读回面"，不是逐个参数找判据** |

⇒ ★★★ **一旦找到那个结构，判据问题一次性解决**  
　 —— 而不是逐个参数去证"改 p7 有没有生效"。
