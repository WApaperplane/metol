# 品牌色系复现：先修一个底层 bug，再按色彩特征验收

2026-10-25 晚。承接 `LUT_DEDUP_AND_GAPFILL_2026-10-25.md`。
本文要报告一件不体面但必须说的事：**上一轮的色彩坐标是错的**，因此那一轮的
六轴结论需要撤回重写。修好之后才做出用户要的冷色/青绿/青橙/金黄与理光蓝、
佳能红、宾得正负逆冲。

## 一、底层 bug：sRGB→XYZ 矩阵乘反了

`similarity_audit.rgb_to_lab()` 把矩阵写成了"行是 RGB 系数"再转置一次，等于用了
转置矩阵。表现：

| 输入 | 错误结果 | 正确结果 |
|---|---|---|
| 纯白 (255,255,255) | L\*=107，a\*=−90.9 | L\*=100，a\*=0 |
| 中性灰 (128,128,128) | a\*=−54.5 | a\*=0 |
| 肤色 (232,190,170) | L\*=87.2，a\*=−55.2 | L\*=80.1，a\*=+12.1 |

中性灰和纯白算出巨大负 a\*，这个"色彩空间"根本不成立。它是个连续单调变换，
所以**距离的排序大体保留**（清理方向没错），但**所有色相/彩度的绝对值都是假的**。

因此上一轮"库是一条窄带，warmth 只有 0.4~11.8、没有偏冷的表"这个结论**作废**。
用正确空间重算：

| 轴 | 我上一轮报的 | 实际（非 gap_ 的原库） |
|---|---|---|
| warmth | 0.4 ~ 11.8 | **−2.3 ~ 11.0**（cool_arctic、fuji_eterna500 本来就是冷的）|
| saturation | 33.7 ~ 56.2 | **0 ~ 38.8** |
| green_mag | −66.7 ~ −33.6 | 改用 a\* 表示：**−2.0 ~ 2.2** |

### 第二个 bug：两个指标测的是同一个量

`shadow_tint` / `high_tint` 原来在 L\*=0 和 L\*=100 处读 b\*。但 `grade()` 的
`endpoints = smooth(0,7,L)` 会在暗端把染色淡出、`protect_white` 在高光端淡出，
所以两处读数都是 0，两个指标同时退化成 `−b*(中灰)`——同一个数算了两遍。上一轮
"分离色调幅度都很小"的判断也由此而来。

改成在输入 45 / 128 / 210 三点读取，并补 `shadow_a` / `high_a` 两个量，四个量才真正独立
（`metrics.py`）。

## 二、原库的真实短板不在冷暖，在绿-品红轴

修正后的原库（不含 gap_）范围：

```
warmth      -2.3 .. 11.0
saturation   0.0 .. 38.8
contrast     0.6 .. 1.3
shadow_tint -10.7 ..  4.6
high_tint   -2.1 .. 11.7
shadow_a    -2.0 ..  2.2      <- 关键
high_a      -1.3 ..  2.5      <- 关键
```

**`shadow_a` 和 `high_a` 都只在一个极窄的正负 2 之内**——也就是说整个库几乎没有
刻意的绿偏或品红偏。这才是"理光蓝不蓝、佳能红不红"的坐标证据：不是冷暖不够，
是**色相方向几乎没被用过**。

旧的 ricoh_*/canon_*/cool_* 十二张表挤在同一格：

```
canon_landscape   warm 2.7  sat 53.5  contr 0.97  hiTw 2.8
ricoh_positive    warm 4.1  sat 50.7  contr 1.01  hiTw 1.9
cool_blue/cyan/mint/slate/steel  warm 0.4~2.7  sat 51~53  contr 0.87~0.95
```

同一个模板换了名字。所以它们被上一轮按距离清掉并不冤——**要做的是重做得有特征，
不是把旧表从归档里搬回来**。

## 三、两条硬约束（先探明，再设计）

写方案前先探参数的真实边界，否则又是在许做不到的愿。

**1. 蓝的"更青"与"更浓"在 sRGB 里互斥**

```
sat_hues{'240'}   C*     hue    a*
1.0              66.3   291.0  23.8
1.3              75.9   289.9  25.8
1.6              77.9   288.0  24.1   <- C* 峰值
2.0              74.8   285.8  20.4
2.6              71.4   283.5  16.7
```

色相往青走必须压低 a\*（引入绿），而绿一多蓝就不纯，C\* 必然回落到 78 以下。
**"理光蓝"因此锁定为"色相更青"，不是"更饱和"**——判据是 hue < 286、C\* > 64、a\* < 20。

**2. 高光染色量由"中灰与高光的 b\* 差"决定，不取决于高光绝对值**

```
mid_b=10 hi_b=13  ->  high_tint  3.1
mid_b= 6 hi_b=16  ->  high_tint  8.3
mid_b= 3 hi_b=18  ->  high_tint 12.5
mid_b= 0 hi_b=20  ->  high_tint 16.7
```

想让高光"金"就必须让中灰"不金"。所以金黄方案的暖度由**阴影段**承担，中灰几乎不加 b。

## 四、7 个方案与验收

identity 基线：蓝 C\* 66.3 / h 291.0，红 C\* 72.4 / h 34.8，肤色 a\* 14.9。

| 文件（`brand_` 前缀） | 蓝 C\*/h | 红 C\*/h | 肤色 a\* | 阴影/− 高光 b | 阴影 a | warmth | sat |
|---|---|---|---|---|---|---|---|
| ricoh_blue 理光蓝 | 65.4 / **278.9** | 69.2 / 32.5 | 14.7 | −3.1 / 1.3 | −1.3 | −6.4 | 32.7 |
| canon_red 佳能红 | 71.6 / 291.3 | **84.7** / 27.2 | **26.0** | 0.2 / 0.8 | 0.3 | 3.5 | 35.8 |
| pentax_crossproc 正负逆冲 | 64.9 / 280.8 | 68.5 / 22.3 | 21.0 | **−8.6 / 10.1** | −3.9 | 0.6 | 36.9 |
| teal_green 青绿 | 60.0 / 284.1 | 61.8 / 32.5 | 12.0 | −5.0 / 3.2 | **−3.2** | −3.5 | 29.1 |
| teal_orange 青橙 | 68.5 / 287.1 | 78.6 / 26.8 | 22.3 | **−12.7 / 13.3** | −3.0 | −2.7 | 34.3 |
| golden_film 金黄 | 48.0 / 287.5 | 74.7 / 29.8 | 17.9 | 13.5 / **16.3** | 1.5 | **10.4** | 29.8 |
| cool_vivid 冷艳 | 68.8 / 281.7 | 69.8 / 23.9 | 17.7 | −2.4 / 0.8 | −0.5 | **−6.7** | 36.8 |

判据（每项都是"这个颜色有没有真的动"）：

- **理光蓝**：蓝色相 291 → **278.9**（−12°)，a\* 从 23.8 降到 20 以下，红绿被压到 0.84~0.86
- **佳能红**：红彩度 72.4 → **84.7**（+17%），色相 27.2 落在暖红段，肤色 a\* 14.9 → 26.0 但没到品红
- **宾得正负逆冲**：对比 >1.15、阴影 −8.6、高光 +10.1，阴影带绿（a −3.9）
- **青绿**：`shadow_a` **−3.2**——超出原库下界（−2.0）
- **青橙**：阴影 −12.7 / 高光 +13.3，**全库最强分离**（原库极值 −10.7 / +11.7）
- **金黄**：warmth 10.4、high_tint 16.3（原库上限 11.7）
- **冷艳**：warmth −6.7 且饱和 36.8——冷但不灰，与 `gap_nordic_overcast` 的低饱和冷区分

**7/7 通过**，且彼此最近一对 3.489 > 项目门槛 3.112。

## 六、遗留与需要重做的地方

- **上一轮的 12 张 `gap_` 方案是在错误坐标下设计的**。它们实际落点用正确坐标看是
  warmth −12.1（nordic）到 +15.9（desert_noon），比原库极值还远——所以"填了空白"
  这个结论碰巧成立，但**设计意图与实测坐标是两回事，不能当作有意为之**。这些表
  保留，但需要按新坐标重新标注目标。
- **清理需要复核**。旧 ΔE00 虽排序大体保留但绝对值不可信。正确空间下重算 75 张，
  最近合法对是 `mono_hard`/`style_noir` 1.361，仍低于 1.5 门槛，可再清一张。
- 宾得正负逆冲是**方向性近似**，不是化学过程的物理模拟（没有做 E-6 与 C-41 的密度
  曲线串联）。
- 理光蓝、佳能红都是**参考风格设计**，不是原厂 profile 反解；原厂没有公开这些风格
  的三维映射。
- 强偏色方案（青橙、逆冲、金黄）只在柜子/玩偶/白墙上验过，**天空、植被、人像肤色
  还没验**——青橙最容易在人像上翻车。
