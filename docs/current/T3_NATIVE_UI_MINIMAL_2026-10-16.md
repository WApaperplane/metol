## 0. 结论（最小接入 = 零 UI 代码补丁的「三件套」）

```
① 显示   M2 文案层：.mo msgstr → 「自定义 1/2/3」显示为配方名（Portra 400 …）
② 值     A2 槽直推：把配方 7 维值写进 PW 槽区（0xdc..0xe2 + 0xda=10）
③ 应用   官方原生选择事务：用户选「Portra 400」（= 官方「自定义1」）→ 官方应用链读槽区 → ISP
```

- **不新增窗口、不加钩子、不改 App 代码**——完全复用原厂菜单/滚轮/触摸/返回语义（GOALS 约束满足）。
- 「选择=应用」的一致性前提（两条，均有既有证据、仅缺实机复核）：
  1. **槽区值 = 配方值**（A2 直推已实证槽区写入 + 应用链）；
  2. **官方「选择自定义 N」会重应用槽区值**（`UI_R1C` 已解出事务结构：写值 → PWB 下发链）。
- **诚实边界**：第一期的**状态反馈受限**（§3）——GOALS 要求的完整状态机呈现需 T5/T8 的额外通道，本期不得伪造（GOALS §1：「不能由菜单改名、软件记账、返回码或参数回读替代」）。

### 1.2 交互映射（第一期）

| 用户动作 | 原厂语义（保持） | 组合三件套后的结果 |
|---|---|---|
| 进「画面向导」 | 打开选项列表 | 列表显示三个配方名（M2） |
| 滚轮移动焦点 | **只改选择**（不应用） | 与 T2 状态机 `selected` 对齐 ✓ |
| OK / 触摸确认 | 选中该档（官方事务：写 `UI_Get_Value` 体系 + PWB 下发） | 「应用 Portra 400」= 官方应用自定义1 槽（A2 已把配方写进该槽） |
| 返回 | 原厂逐级退出 | 不变 |
| 再选其它档（OFF/标准…） | 官方语义 | 不变（**不劫持**——三件套只影响 CUSTOM 三条的「名字 + 内容」） |

### 1.3 与官方「其它 11 档」的关系

- 三件套**不改变**官方 11 个风格档与 CUSTOM 的**行为**；只让 CUSTOM1/2/3 的**名字**与**内容**变成我们指定的三份预设。
- 用户对三槽的手工调参仍然有效（官方行为）——此时应触发 T2 的 `external_modified`（检测属 T5）。

## 2. 应用通道选型（三候选）

| # | 候选 | 机制 | 需补丁？ | 第一期结论 |
|---|---|---|---|---|
| **a ★** | **官方原生选择事务** | 用户选 CUSTOM N → 官方链（`GUI_Set_System_Value(4,4,id,val)` → PWB 下发 → `mm_camera_capture_still`/`CMCBAdapter::SendCommand(0x201,48B)`） | **无** | **采用**（零补丁，最贴原生语义） |
| b | C-2 命令桥 | `st app film <…>` → `f.sh` 分发（PW/LUT 脚本动作） | 无（已备，待上机） | 备选：脚本/自动化路径（非 UI 路径） |
| c | App 内统一控制器 | 按 T2 协议在 App 内实现适配器 + 状态机 | **有**（代码注入，重） | 后置（依赖 T5/T7 的通道裁决） |

- **推荐 a** 的理由：GOALS 要求「复用既有菜单链」；a 是唯一**无需任何代码改动**即可满足「选择→确认→返回」的路径。
- **a 的两个待复核点**（上机，§4）：① 官方「选择」是否**重读槽区**（若官方缓存了旧值，则需先经 b 刷新）；② 确认后**画面变化是否可靠可复现**。
- b 与 a **不互斥**：b 可用于「程序化预置槽值」（A2 直推即此角色——已实证）。

## 3. 状态反馈能力矩阵（诚实边界）

| T2 状态 | 第一期能否呈现 | 手段 / 限制 |
|---|---|---|
| `selected` | ✅ | 原生焦点（滚轮/触摸） |
| `applied`（预览生效） | ✅ **间接** | 画面变化（用户直接可见）——**这就是「效果可见」的唯一硬证据** |
| `partial` / `failed` | ❌ | **无 UI 通道**（.mo 为静态文案；无运行时文本注入通道）⇒ 不得伪造成功/失败提示 |
| `preview_only` vs `still_verified` | ❌（UI 文本） | 只能写进**静态帮助文本**（.mo 已有 `MSG_MENU_PW_*` 描述位——可在文案层如实说明「预览生效」） |
| `external_modified` | ❌ | 需检测通道（varlist/Cfg 采样）——T5/T8 |

⇒ **第一期产品口径**（与 GOALS §6 交付分级一致）：
**交付「原生入口 + 名称正确 + 效果可见」**；状态机的完整呈现**明确列为后续**。
静态文案位（选项表 `+0x20` 的 MSG 字段，`0x47F9E0/FA04/FA28`）可作为**诚实说明**的落点（例：「预览生效；成片需后处理」），属 M2 文案工艺的可选扩展。
