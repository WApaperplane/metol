# NX-WA 2.88.0-nxwa.15.4

发布日期：2026-11-14
两条来自 GitHub Discussion 的用户报告 + 一批 15.3 之后没发的修复。

## 一、换配方会改掉别的自定义档（已修）

用户停在**自定义2**时浏览或提交 FilmLab 配方，自定义2 也变成配方效果。
原因是 A2 直推的改动被相机归属到"发送那一刻仍在用的那一档"，而引擎只写、只备份了自定义1。

现在直推**之前**先把档位落到自定义1；打开面板时所在那一档也会备份。
实测：自定义2 在提交后逐值不变。

## 二、装 mod 后无法录像、卡顿（已修）

开机脚本把码率顶到 4K-Pro **160** / HD-Pro **180 Mbps**（约 20 MB/s 持续写），
普通 UHS-I 卡只有 10 MB/s，缓冲一满就卡 UI、随后录像 abort。原厂 4K Pro 约 60。

默认改为 `80 / 100 / 50 / 60 / 40`，菜单「视频码率」仍可逐档调高且重启保留。
实测录像 4 秒 = 40.4 MB ≈ 80 Mbps。**如果你的卡仍然吃不住，请降到 50。**

## 三、15.3 之后的其他修复

- **「还原原厂」不再假成功**：A18 还原点 0 字节时原来只打一行 WARN 就跳过，现在会退到随包基线并自证。
- **SD 卡状态层**：这张卡的 exFAT 在覆盖式 rename 时**不替换目标**，每次写留一个旧目录项
  （实测 10 次 → 11 项）。易失状态改走 tmpfs，持久文件改走 `rm` 前置的原子替换。
- **预览提速**：FilmLab 面板浏览 930 → 552/455 ms（只推变化的维）。
- **文档**：LUT 录像的首帧机制早就换成"23 项档位指针表整体指 A18"，旧文档里
  "不保证第一帧带 LUT"的表述已作废；连续录制 **4 分钟实测正常**。

## 五、升级

解压到 SD 卡根 → 插卡 → 等自动同步完成 → 重启。码率改动在**重启后**生效。

## 边界

LUT 录像的更多帧率组合仍未覆盖；码率下调是默认值，不是上限。
