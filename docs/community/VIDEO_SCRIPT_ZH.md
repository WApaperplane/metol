# 短视频脚本 · NX500 实时 3D LUT

> 平台：抖音（竖屏 1080×1920，45s 主版 + 22s 快剪版）｜小红书（同素材，45s 版 + 图文笔记）
> 核心卖点只有一句话：**不刷固件，改 4 个字节，取景器变成任意 3D LUT。**
> 全片不解释原理，只给「看见的变化」。原理留给评论区。

## 一、45 秒主版（抖音 / 小红书通用）

| 时间 | 画面 | 屏幕字幕 | 口播（可选） |
|---|---|---|---|
| 0.0–2.5s | **钩子**：取景器画面满屏正常 → 一帧之内切成负片。无转场，硬切。 | 无字幕 | 无（只有快门"咔"的实录音） |
| 2.5–6.0s | 手入画，半按快门。画面从负片变回正常。 | 不刷固件<br>改 4 个字节 | — |
| 6.0–11.0s | 特写：手指在机顶拨轮/面板上点一下；取景器画面立刻换色（warm33 → neg → identity17） | 点击即换<br>任意 3D LUT | 这台是 2015 年的三星 NX500 |
| 11.0–17.0s | 桌面俯拍：一张纸上写 `4 字节`，旁边写 `19,712 字节`，用红笔圈出 `4` | 只改 4 个字节的登记表<br>表本身 19,712 字节 | 换一张表，只动一个 word |
| 17.0–24.0s | **最有价值的一镜**：左画面 = 取景器（正常），右画面 = 刚拍的成片（负片） | 取景正常<br>成片负片 | 两条链路是分开的 |
| 24.0–30.0s | SD 卡插入读卡器 → 屏幕上 `portra400.cube` 拖进 `looks/` 文件夹 | `.cube` 丢进 SD 卡 | 不用电脑，机上直接转 |
| 30.0–36.0s | 相机屏幕上的 LUT 面板（720×192，三个滤镜块） | 机上 UI<br>不是手机 App | — |
| 36.0–41.0s | 取景器里同一场景，四个不同风格连切（每 1.2s 一个） | 一条链路<br>无限张表 | — |
| 41.0–45.0s | 黑底白字：`github.com/WApaperplane/metol` | 全部开源 · AGPL-3.0 | 代码和实验记录都在仓库里 |

**节奏要点**

- 0–2.5s 不要任何 logo、标题、自我介绍。前 2 秒只有「变化」。
- 负片那一刀要卡在 BGM 的第一个重音上。
- 11–17s 是全片唯一的"信息段"，控制在一句话之内，再长就划走了。
- 结尾不放"点赞关注"，放仓库地址 —— 这个内容的受众会自己去搜。

## 五、拍摄清单（实拍前先对）

| 镜头 | 怎么拍 | 坑 |
|---|---|---|
| 取景器画面 | **首选**：micro-HDMI 输出接采集卡录屏。**备选**：手机贴脸拍 EVF，手动锁定曝光与对焦 | HDMI 若有菜单叠加就退回贴脸拍；EVF 是 OLED，手机拍摄会出现扫描条纹，把手机快门调到 1/50 或 1/60 试 |
| 「点一下换色」 | 手机录屏式固定机位，只拍手指和屏幕；后期裁竖屏 | 面板是 720×192 的横条，竖屏里会很小 —— 后期做局部放大 + 画中画 |
| 半按快门 | 侧逆光拍手部特写，能看见手指压下去 | 半按会触发对焦，画面可能呼吸，选固定焦点场景 |
| 成片对比 | 直接把 `SAM_0044.JPG`（负片）和取景器截图并排 | 成片是 7.7 MB 原图，导出 2048px 长边再上屏 |
| `.cube` 拖卡 | 桌面俯拍，手要慢，动作要完整 | 别用真实路径特写（会暴露盘符），模糊处理或只拍文件名 |

- `raw8/gates/lut/regtab_2026-10-18/lut_ui2.png` —— LUT 面板（720×192）
- `raw8/gates/lut/regtab_2026-10-18/photos/SAM_0044.JPG` —— 负片成片（关键证据）

## 六、BGM 与音效

- 风格：低频、克制、带一点机械感（类似 minimal techno），不要燃向。
- 关键音效三个：**快门咔哒**（开场负片那一刀）、**拨轮咔**（换表）、**电流嗡**（开机）。
- 不要用"科技感电子音效包"，会显得像贴片广告。

**正文（可直接复制）**

```
这台是 2015 年的三星 NX500。

它里面有两个 CPU，色彩全归那颗叫 p7 的图像处理器管。
p7 把 3D LUT 放在内存的 42 个槽里，每次装载都重新读一次代码段里的登记表。

所以换一张表，只需要：
改 1 个 4 字节的登记表项
写 19,712 字节进空闲槽
半按一次快门

不刷固件，不改固件代码，不用抢时序。断电就回原样。

更意外的是：取景和成片是两张独立的登记表。
也就是说，可以让取景器显示一个风格，让 JPEG 出另一个风格 ——
上面那组「取景正常、成片负片」就是这么拍的。

.cube 文件直接丢进 SD 卡，相机上一条命令转成槽表，不需要电脑。

全部开源，实验记录、地址表、判据都在仓库里：
github.com/WApaperplane/metol

#摄影 #胶片模拟 #LUT #相机改装 #三星NX500 #逆向工程 #开源 #数码影像
```

## 八、发布顺序建议

1. **先发 Reddit**（`r/SamsungNX` + `r/cameras`）—— 那边会给技术反馈，能补进下一条视频的评论区置顶。
2. **再发小红书图文**，视频晚 1–2 天 —— 图文先测标题，视频用测出来的钩子。
3. **最后发抖音**，因为抖音的完播率对前 2 秒最敏感，等钩子被验证过再投。
4. 三个平台都在评论区置顶同一条：「有不同 p7 固件版本的，帮我跑一下 `nx_regtabdump` 对地址表」—— 把观众变成协作者，这是这个项目唯一能扩展的方式。
