# NX500 SSH / SFTP 使用教程

相机地址 **192.168.0.106**，端口 **22**，账号 **root**，**密码留空**（`-B` 允许空密码，也可用公钥）。
前提：相机开机、连上同一 WiFi、没休眠（休眠后 21/22/23 全部拒连）。

---

## 一、一分钟上手

```bash
cd E:/NXWA/nx500-modding-work

bash tools/nx-ssh.sh                        # 直接进相机 shell
bash tools/nx-ssh.sh cmd 'ls /opt/usr/nx-ks' # 执行单条命令

bash tools/nx-photos.sh sync E:/NXWA/_photos # 增量拉回来
bash tools/nx-photos.sh album E:/NXWA/_photos # 生成本地相册并打开
```

## 二、图形化浏览（WinSCP / FileZilla）

装好后新建站点，四个字段填完即可连：

| 字段 | 填什么 |
|---|---|
| 协议 / 文件协议 | **SFTP**（不是 FTP、不是 SCP） |
| 主机名 | `192.168.0.106` |
| 端口 | `22` |
| 用户名 | `root` |
| 密码 | **留空**，直接确定 |

连上后就是标准的双栏文件管理器：左边本地、右边相机。

- 照片在 `/opt/storage/sdcard/DCIM/100PHOTO/`（SD 卡）
- `/mnt/mmc` 是同一个地方的软链接，两个路径都行
- 拖拽即传，右键可改权限；WinSCP 双击图片会调内置查看器

> WinSCP 若坚持要钥匙文件：本机私钥在 `test_server/dropbear/ssh/nx500_ed25519`，但那是 OpenSSH 格式，WinSCP 需要 `.ppk`（用 PuTTYgen 的 Conversions → Import key 转一次即可）。**不想折腾就直接用空密码**。

## 三、命令行速查

```bash
KEY=E:/NXWA/nx500-modding-work/test_server/dropbear/ssh/nx500_ed25519
CAM=root@192.168.0.106
OPTS="-o IdentitiesOnly=yes -o StrictHostKeyChecking=no -o UserKnownHostsFile=/dev/null -o LogLevel=ERROR"

# 登录
ssh -p 22 -i $KEY $OPTS $CAM

# 单条命令
ssh -p 22 -i $KEY $OPTS $CAM 'df -h; uptime'

# 下载（sftp 端口是大写 -P，跟 ssh 的 -p 不同）
scp -P 22 -i $KEY $OPTS $CAM:/opt/storage/sdcard/DCIM/100PHOTO/SAM_0001.JPG ./

# 上传
scp -P 22 -i $KEY $OPTS ./nxui.arm $CAM:/opt/usr/nx-ks/

# 交互式 sftp
sftp -P 22 -i $KEY $OPTS $CAM
sftp> cd /opt/storage/sdcard/DCIM/100PHOTO
sftp> ls
sftp> get SAM_0001.JPG
sftp> put 本地文件
sftp> quit
```

**不用密钥也行**（空密码）：

```bash
ssh -o PreferredAuthentications=password -o PubkeyAuthentication=no root@192.168.0.106
# 提示 password 时直接回车
```

## 四、看图的三条路

| 场景 | 做法 | 体验 |
|---|---|---|
| 随手翻几张 | WinSCP 连上，双击 JPG | 最快，不用等全下 |
| 全部取回本地 | `nx-photos.sh sync <目录>` | 增量，已有同大小跳过 |
| 要浏览相册 | `nx-photos.sh album <目录>` | 生成 `_album.html`，网格缩略图，点开看原图 |

`album` 生成的是纯本地页面（`<img loading=lazy>`），不依赖网络，双击即开。

**速度参考**（2026-10-23 实测，`-O2` + `nice 0`）：约 **1.4–1.6 MB/s**。一张 10MB 的 JPG 约 6–7 秒，156MB 的 16 张**约 2 分钟**。

历史配置只有 0.5–0.8 MB/s，原因是 dropbear 继承了 Tizen telnet shell 的 `nice=19`（最低优先级），和相机主业务抢不到 CPU —— 与编译优化关系不大。现已由 `run.sh` 用 `renice 0` 修正，**不要绕过它直接起 dropbear**。

只看缩略图的话，建议直接用 WinSCP 双击——它会先拉整张，但单张等待可接受。

## 五、常见问题

**连不上**
1. `ping 192.168.0.106` 通不通
2. 通了但 22 拒连 → 相机可能休眠了，按一下快门唤醒
3. 相机刚开机 → 等 1 分钟（`init.sh` 在 boot+37s 左右才拉起 dropbear）

**`Permission denied (publickey)`**
公钥没装好。用空密码先登进去，跑一次 `/opt/usr/nx-ks/dropbear/restart.sh`，它会顺带恢复 `authorized_keys`。

**`Connection closed` / `subsystem sftp not found`**
sftp-server 不见了。检查 `/opt/usr/nx-ks/dropbear/sftp-server` 是否存在且可执行（`chmod +x`）。路径是编译期写死的，不能挪位置。

**怎么重启 sshd**

```bash
bash tools/nx-ssh.sh cmd 'sh /opt/usr/nx-ks/dropbear/restart.sh'
```

**改了端口/换了二进制后**

```bash
bash tools/nx-ssh.sh cmd 'sh /opt/usr/nx-ks/dropbear/restart.sh 2222'
```

**日志在哪**

```bash
bash tools/nx-ssh.sh cmd 'tail -20 /tmp/db.log'
```

**别忘了 telnet 还在**
22 挂了不影响排障：telnet 23 / FTP 21 依旧是备用通道（`E:/NXWA/_cam.py` 比 `nx-telnet.py` 稳）。

## 六、端口对照

| 端口 | 服务 | 用途 |
|---|---|---|
| 21 | FTP (busybox ftpd) | 老通道，根 = SD 卡 |
| 22 | **dropbear ssh / sftp** | 本教程 |
| 23 | telnet | 排障后路 |
| 80 | NX 远程控制器 | 浏览器遥控相机 UI |
